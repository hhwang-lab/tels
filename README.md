# 情緒素養量表｜35 題自我檢視網站

這是一個清新簡潔的 35 題情緒素養量表網站，依照論文中的四因素計算：

| 因素 | 本網站題號 | 論文教師樣本平均 |
| --- | ---: | ---: |
| 自我覺察 | 1–9 | 4.94 |
| 自我管理 | 10–20 | 4.46 |
| 社會覺察 | 21–27 | 5.00 |
| 人際技能 | 28–35 | 4.67 |
| 總量表 | 1–35 | 4.74 |

平均數都是六點量表的「題目平均」，因此可以直接與論文數值對照。35 題皆採正向計分，沒有反向題。

## 立即使用

直接用瀏覽器開啟 `index.html` 即可填答。網站會：

- 自動保存尚未完成的草稿。
- 完成後計算四因素原始分數、題目平均與總量表平均。
- 將個人分數與論文教師樣本平均並列比較。
- 在「資料後台」累積本機匿名回覆，並匯出 CSV／JSON。
- 支援列印或另存成 PDF 的個人報表。

本機模式的資料只存在目前瀏覽器的 `localStorage`，不會自動同步到其他裝置。

## 讓回覆集中累積到 Google 試算表

專案內的 `Code.gs` 是 Apps Script 後端範本。它會把回覆寫入 Google 試算表的 `回覆` 分頁，並用 Script Properties 保存後台代碼。

1. 建立一份 Google 試算表，從「擴充功能 → Apps Script」開啟綁定腳本。
2. 將 `Code.gs` 內容貼入 Apps Script 的 `Code.gs`。
3. 新增一個 HTML 檔案，檔名只填 `index`，將本專案 `index.html` 完整貼入。
4. 儲存後，先執行 `setupScaleBackend()`，再執行 `setAdminToken()` 設定至少 8 碼的後台代碼。
5. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分選「我」、誰可以存取選「所有人」。
6. 以部署網址（結尾為 `/exec`）開啟網站；此時填答會寫入試算表，後台會要求剛才設定的代碼。

修改內容後，請在「管理部署作業」用鉛筆編輯同一個部署並選新版本，網址才會維持不變。

## 資料保護提醒

這個工具預設只收答案、匿名編號與時間，不收姓名、Email、身分證字號或健康資料。若公開部署，請把試算表維持私有、定期備份，並在活動結束後停用或封存部署。

結果是自我反思與專業發展參考，不是心理或醫療診斷，也不應作為個人排名依據。
